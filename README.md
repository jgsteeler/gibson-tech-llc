# Gibson Tech Works (gibsontechworks.com)

> *"The technology just works—because good architecture works."*

Lightweight Astro static marketing and lead-generation site for **Gibson Tech, LLC**, engineered to attract high-value enterprise consulting, AppSec audit defense, and fractional systems architecture engagements.

---

## 1. Core Positioning & Revenue Strategy

This site's current mission is **not** to market or sell early-stage SaaS applications or shop tools. It is an executive-level consulting funnel designed to generate immediate, high-margin revenue through Corp-to-Corp (C2C) advisory and contract architecture:

* **AppSec & Pen-Test Readiness Sprints:** Eliminating third-party penetration test findings before auditors arrive; hardening OAuth 2.0 PKCE, Okta CIAM migrations, and OWASP API Top 10 boundaries across healthcare and financial backends.
* **Fractional Principal Architect Sounding Board:** Serving as a confidential, objective sounding board for Engineering Directors and VPs; decoupling monolithic legacy backends into Clean/Onion Architecture and CQRS event streams.
* **"Vibe to Enterprise" AI Engineering Mentorship:** Interactive workshops and PR triage mobs coaching developer teams adopting GitHub Copilot and Cursor to move past isolated, brittle "vibe coding" into disciplined SOLID systems thinking.
* **Opportunistic Executive Roles:** Signaling availability for high-impact C2C consulting contracts ($125–$150+/hr) or elite remote software architect positions ($195k–$200k+).

## 2. Search & Discovery Optimization Lens

The copy, structure, and metadata are calibrated so that technical leaders find Gibson Tech when searching or querying AI tools:

1. **The Frustrated Engineering Director:** Looking for ways to help talented junior engineers see system-wide dependencies, adhere to architectural standards, and stop shipping isolated, buggy features generated by AI.

3. **The Modernization Leader:** Navigating legacy .NET or cloud migrations (Azure APIM, OpenShift/ARO, AWS) who needs veteran, battle-tested direction without agency overhead.
4. **The High-End Recruiter / Hiring Executive:** Sourcing language-agnostic senior problem solvers with ~25 years of enterprise experience across high-stakes healthcare and financial domains.

## 4. Technical Stack & Simplicity

The website architecture is intentionally kept minimal and rock-solid:

* **Static Architecture:** Built with [Astro](https://astro.build/) using component-driven sections in `src/components/home/`.
* **Styling:** Scoped CSS with Kansas City Royals heritage palette variables and local storage theme toggle (`src/styles/home.css`).
* **Deployment:** Hosted on [Netlify](https://www.netlify.com/) via `netlify.toml` with simple git-push deploys (`build = npm run build`, `publish = dist`). Zero runtime scaling complexity, serverless bloat, or edge overhead.
* **Feature Flag Governance:** Centralized in `src/config/features.ts`. All pricing tags ($3.5k–$5k sprint, $125–$150/hr retainer, $3,500 workshop) and direct booking CTAs are strictly guarded behind feature flags, keeping the live site in clean vanilla discovery mode until explicitly flipped.
