# Gibson Tech Website

Astro marketing site for Gibson Tech, LLC (brand: Gibson Tech / G Tech), centered on Divergent
Engine and Divergent Flow.

## Positioning Summary

- Legal name: Gibson Tech, LLC
- Brand name: Gibson Tech / G Tech
- Core platform thesis: Build around Divergent Engine
- Flagship product: Divergent Flow (client zero)
- Revenue lanes: Product subscriptions, plugin marketplace, premium plugins, speaking, training,
  and consulting

## Local Development

```sh
npm install
npm run dev
```

Site runs at `http://localhost:4321`.

## Build

```sh
npm run build
npm run preview
```

## Deployment

Netlify config is in `netlify.toml`.

- Build command: `npm run build`
- Publish directory: `dist`

## Key Files

- `src/pages/index.astro`: Main homepage content and styling
- `netlify.toml`: Netlify deployment settings
- `.github/copilot-instructions.md`: Workspace execution checklist and setup tracking
